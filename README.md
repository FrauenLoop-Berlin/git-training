# git-training

1. Create a branch of this repo `git switch -c newBranch`, make some change to this file, save it, add and commit it with `git add .` and `git commit -m "describe your change` and  upload it again with `git push`.
2. create another branch using the same command and make some changes to it and commit the changes
3. try to merge the two branches with `git merge nameOfBranchToMerge`
